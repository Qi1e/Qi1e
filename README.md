#### 项目

**[ToDone](https://github.com/Qi1e/ToDone)** · 鸿蒙原生事项管理应用
把「记录 / 计数 / 截止日期」抽象成可自由组合的事项模块，用一套数据结构支撑习惯打卡、次数统计、日程管理三类场景；打通桌面服务卡片与本地存储，不打开 App 也能记录。
`ArkTS` `ArkUI` `Stage 模型` `服务卡片` · 有[产品规格](https://github.com/Qi1e/ToDone/blob/main/PROJECT_SPEC.md)和[技术决策记录](https://github.com/Qi1e/ToDone/blob/main/DECISIONS.md)

**[GamePulse](https://github.com/Qi1e/GamePulse)** · macOS 菜单栏 glanceable 趋势框架
把「值得留意、但不值得为它开一个窗口」的实时信号，压缩成菜单栏里一条可扫视的 Pulse。核心是 Attention Router：用 salience 评分决定此刻哪条信号最该打断你。
`AppKit` `NSStatusItem / NSPopover` `WKWebView` `NBA live API` · 课程合作项目，[原始仓库](https://github.com/lingcang728/GamePulse)

**[raspbot_posture](https://github.com/Qi1e/raspbot_posture)** · 视觉追踪智能小车
树莓派 + 麦克纳姆轮 + MediaPipe Pose：人体追踪、底盘跟随与 3 类动作计数（深蹲 / 箭步蹲 / 波比跳），实测约 15 FPS、端到端延迟低于 100ms。
`Python` `OpenCV` `MediaPipe` `比例控制 / 短脉冲` `串口` `I2C` · 4 人课程项目，本人负责全向追踪链路与日志模块

**[锈蚀酒馆 RustyBar](https://www.taptap.cn/app/854726)** · Roguelike 独立游戏
